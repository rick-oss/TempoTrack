## 🧠 Visão Geral

    - Aplicativo de previsão do tempo feita em React.
    - Exibe a previsão atual, para amanhã e para os próximos 5 dias.
    - Usa geolocalização ou cidade pesquisada via MapBox.
    - Fundo dinâmico baseado no clima atual.
    - Permite alterar de temperaturas entre °C e °F.
    - Tema Responsivo otimizado pra celular.

## ⚙️ Tecnologias e Ferramentas

    - React
    - Vite(build com cache busting por hash)
    - CSS Modules
    - MapBox API(autocomplete de cidades)
    - OpenWeatherMap API(dados do tempo)
    - Vercel(Deploy)
    - Git + Github

## 💡 Funcionalidades

    - Barra de pesquisa com autocomplete
    - Busca por geolocalização
    - Fallback para busca manual caso a permissão de localização seja negada
    - previsão atual completa:
      - Temperatura
      - Máximas e mínimas
      - Umidade
      - Velocidade do vento
      - Sensação térmica
    - Previsão para o dia seguinte
    - Previsão para os próximos 5 dias
    - Fundo dinâmico de acordo com a condição do tempo atual
    - Botão de alternância entre Celsius e fahrenheit
    - Layout responsivo, otimizado para dispositivos móveis
    - Mensagens de erro (flash messages) para feedback claro ao usuário
